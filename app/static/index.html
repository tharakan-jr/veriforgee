CRITICAL Line 1 in artefact.py CWE-798

Hardcoded database password

Your database password is written directly inside the source code. If this code is shared or uploaded to a public repository, someone could potentially obtain the password.

Flagged Code Line Vulnerable Code
1 DB_PASSWORD = "admin123" ⚠️ Plaintext Secret
🔑
Security Key Metaphor

Think of the password as a key. Putting the key inside the source code means anyone who gets the code may also get the key.

Real-world Impact: Once committed, hardcoded secrets remain in Git repository commit history permanently unless forcefully purged with repository rewriting tools.
Finding Exposed Secret
➔
Security Rule CWE-798 Standard
➔
Trusted Evidence OWASP Top 10 A07
Authoritative Guidance MITRE Common Weakness Enumeration CWE-798
"Secrets should not be embedded directly in source code. Use a secure secrets/environment-variable mechanism instead."
Why this applies: The literal string assigned to DB_PASSWORD matches an unencrypted database credential stored in plaintext within source code.

Store the password in an environment variable instead of putting it directly in the source code.

Unsafe Original - Line 1 
DB_PASSWORD = "admin123"
Recommended Safe Code + Lines 1-3 
import os

DB_PASSWORD = os.environ.get("DB_PASSWORD")
Developer Tip: Use a .env file on your local machine and ensure .env is added to your .gitignore so private keys never reach source control.
