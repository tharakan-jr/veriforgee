# Dataset & grounding notes

The hackathon problem statement requires teams to source and prepare their own datasets for review, explanation, grounding, or classification components. Possible sources include public vulnerability databases, open-source repositories, openly licensed technical documentation, and self-generated samples, with origin and licensing documented in the submission.

For the MVP, prefer a small, curated set of high-confidence rules over a large noisy corpus.

Track for every source:

- source name
- URL / identifier
- licence / usage terms
- retrieval date
- rule or finding categories covered
- how it is used in the product
